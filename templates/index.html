      Key catalogue
      

    


    

      Command reference
      

        
type <text>Type literal text

        
key <combo> [ms]Tap a combo, e.g. ctrl+alt+delete, f5, up

        
paste <text>Clipboard + Ctrl+V. Instant, and types anything — emoji, —, accents (needs agent)

        
clip <var>Read the PC clipboard into a variable (needs agent)

        
waitfor window <t> [ms]Block until that window is focused — better than guessing a delay

        
waitfor pixel <x> <y> <#rrggbb> [ms]Block until a pixel turns that colour

        
getpixel <x> <y> <var>Read a pixel colour into a variable

        
jumpif <var> <op> <val> <label>Branch: jumpif i < 5 loop. Ops: < <= > >= == != contains

        
moveto <x> <y>Move the mouse to an absolute pixel position

        
move <dx> <dy>Move relative to the last position

        
click [button] [n]click, click right, click left 2

        
mousedown/mouseupHold a button (drag): mousedown left … mouseup

        
scroll <n>Wheel; positive up, negative down

        
screen <w> <h>Tell the Pi your resolution (default 1920x1080)

        
anchor <window>Make following x/y relative to that window's client area; anchor none to reset

        
focus <window>Switch to a window by title or exe (needs the PC agent): focus Notepad

        
set <name> <value>Define a variable: set n 3, set who Max

        
add <name> <n>Add to a number (negative to subtract); unset starts at 0

        
$nameUse a variable anywhere: type hi $who, repeat $n, delay $w. $$ is a literal $

        
hold <combo>Press and hold (key down) — stays down until released

        
release [combo]Key up: release that combo, or everything if omitted

        
delay <ms>Wait, e.g. delay 250

        
delay <a>-<b>Random wait, e.g. delay 100-400

        
repeat <n> … endLoop n times (or repeat forever)

        
label <name>Mark a position

        
goto <name>Jump to a label

        
chance <pct> <cmd>Run cmd n% of the time

        
oneof a|b|cType one option at random
